# GoldPrice · 个人金价状态栏

基于 [Tespera/GoldPrice](https://github.com/Tespera/GoldPrice) 的个人定制版，维护于 [Abbylolo/GoldPrice](https://github.com/Abbylolo/GoldPrice)。原生 macOS 菜单栏应用，展示招商银行黄金账户报价、国内 Au99.99 趋势和伦敦现货金。

## 功能

- 状态栏可选择招行客户买入价、招行客户卖出价或伦敦现货金；选择会保存。
- 招行买卖报价分别展示，人民币/克；伦敦现货金使用美元/盎司。
- 趋势图支持当日、近一月、三月、六月、一年、全部；悬停可读价。
- 手工录入实际买入、卖出、克数、成交单价、总手续费，自动计算持仓均价、持有克数、浮动收益/收益率及已实现收益。
- 按渠道设置达到或高于/低于指定价格的系统提醒，等于阈值也触发；每条规则提醒一次，可重新开启。
- 设置刷新间隔、登录自启；交易数据和提醒保存在本机，支持导出 JSON 备份。

## 数据来源与覆盖

| 数据 | 来源 | 覆盖与口径 |
| --- | --- | --- |
| 招行实时买卖价 | 招商银行 `product/v1/func/market-center` | 读取 `zBuyPrc`、`zSelPrc`，保留接口报价时间，不换成其他渠道的估算价 |
| 国内趋势 | 东方财富 `118.AU9999` 日线及分钟线（上金所 Au99.99） | 公开历史从 2004-01-02 起；与上方招行客户买卖价存在价差，不作为招行历史或持仓估值 |
| 伦敦现货实时价 | 新浪 `hf_XAU` | XAU 现货，未混用纽约黄金期货 |
| 伦敦现货历史 | 东方财富 `122.XAU` 分钟线和日线 | 本次验证日线为 1992-05-19 至 2026-10-29。实际覆盖以接口结果为准，当日使用分钟线，其余范围使用日线 |

“全部”指可获取数据的最早日期起。现货黄金没有基金意义上的“成立日”。图表标注数据品种、来源和真实覆盖日期。国内趋势直接联网获取，无需应用常开积累；不再记录本机采样。旧版数据中的持仓、交易、提醒和设置兼容读取。

实时报价使用 URLSession；国内及伦敦历史通过 macOS 自带的 `/usr/bin/curl` 获取同一接口，兼容部分 CFNetwork 环境下的大响应中断。日线缓存每天自动更新一次，也支持手动刷新，避免频繁重复下载长期数据。下载在后台执行，无需安装依赖或打开终端。

报价过期时仍可查看最近报价及时间，但不会用过期报价触发价格提醒。提醒依赖应用运行、Mac 唤醒、有效网络报价和系统通知权限。

## 持仓计算

采用移动加权平均成本，金额用 `Decimal` 计算：

- 买入：剩余成本增加 `成交克数 × 成交价 + 显式手续费`；均价为剩余成本除以剩余克数。
- 卖出：按卖出前的持仓均价结转成本；剩余持仓均价不变。
- 已实现收益：`卖出金额 - 卖出手续费 - 结转成本`。
- 浮动收益：`剩余克数 × 招行客户卖出价 - 剩余成本`。
- 持仓收益率：浮动收益除以剩余成本。全部卖出后成本归零，新一轮买入重新计算均价。

客户买卖报价中的点差已体现在成交价中，不会额外重复扣除。手续费字段仅填写成交价以外的显式费用。卖出超过当时持仓、负数、无效价格会被拒绝；补录或删除旧交易后会按时间重算并重新校验。

交易录入只是个人记账，不连接银行账户、不发送银行交易指令。

## 本地开发

要求 macOS 13+、Swift 6 工具链（应用源码使用 Swift 5 语言模式），无第三方依赖。

```sh
swift test
swift run GoldPrice --preview
```

`--preview` 以普通窗口打开和菜单栏完全相同的界面，方便本地调试。可以用独立目录进行 UI 验证，避免写入日常数据：

```sh
swift run GoldPrice --preview --data-directory /tmp/goldprice-personal-qa
```

## 打包与安装

```sh
bash scripts/build-app.sh
```

生成 `Build/GoldPrice.app` 和对应架构 ZIP。将应用移到“应用程序”文件夹后打开，在设置中选择状态栏渠道、开启登录自启。

本地打包使用临时签名，不包含 Apple Developer ID 公证。应用标识为 `com.abbylolo.goldprice`，与原版区别；默认数据目录为 `~/Library/Application Support/GoldPricePersonal/`。

仓库包含分支/PR 测试与 Release 工作流：分支和 PR 运行测试及构建；`v*` tag 构建 ARM/Intel 安装包并创建 Release 草稿。需在自己的 Fork 中启用 Actions。

## 代码结构

- `GoldPriceApp.swift`：应用入口和系统通知代理。
- `StatusBarController.swift`：菜单栏、弹出面板、开发预览窗口。
- `GoldPriceView.swift`：行情、持仓、提醒、设置的 SwiftUI 界面和原生图表。
- `GoldPriceService.swift`：招行、伦敦实时报价和伦敦历史网络请求。
- `AppStore.swift`：刷新、状态、本地存储和系统通知投递。
- `Sources/GoldPriceCore/`：纯 Foundation 的行情解析、持仓计算和提醒判定。
- `Tests/GoldPriceCoreTests/`：金额计算、超卖、回溯交易、接口字段和提醒边界测试。
